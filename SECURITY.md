# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ZIMS, please report it privately before making it public.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x | ✅ Yes |
| 0.x | ❌ No |

## Response Time

- Initial response: Within 48 hours
- Fix target: As soon as possible

Thank you for helping keep ZIMS secure.
