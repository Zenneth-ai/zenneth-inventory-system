# Zenneth Inventory Management System (ZIMS)

A modern web-based inventory management system for Zenneth Gas Suppliers.

## Features

- Secure User Login
- Dashboard
- Inventory Management
- LPG Cylinder Tracking
- Accessories Management
- Suppliers
- Customers
- Stock In
- Stock Out
- Reports
- User Roles

## Technologies

- Laravel
- MySQL
- Bootstrap
- GitHub

🚧 Project planning and development in progress.
