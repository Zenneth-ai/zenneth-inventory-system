# Contributing to ZIMS

Thank you for contributing to the Zenneth Inventory Management System (ZIMS).

## Branching Strategy

- main - Stable production branch
- develop - Active development
- feature/* - New features
- bugfix/* - Bug fixes

## Commit Messages

Examples:

- Add login page
- Fix inventory calculation
- Update dashboard layout
- Improve sales workflow

## Code Standards

- Write clean, readable code.
- Document major features.
- Test before merging.
- Keep commits small and meaningful.
