# ZIMS Cylinder Exchange Workflow

## Cylinder Exchange Process

1. User logs in.
2. Search or register customer.
3. Record empty cylinders returned.
4. Select full cylinders to issue.
5. Calculate exchange fee (if applicable).
6. Confirm transaction.
7. Update cylinder inventory automatically.
8. Generate receipt.
9. Save exchange history.
10. Record activity in audit logs.

## Validation Rules

- Customer cannot receive more full cylinders than allowed.
- Empty cylinders must be inspected before acceptance.
- All exchanges must be linked to a user account.
