# ZIMS Inventory Workflow

## Stock Receiving

1. User logs in.
2. Select supplier.
3. Receive products.
4. Verify quantities.
5. Update inventory.
6. Record stock movement.

## Stock Issuing

1. Select products.
2. Enter quantity.
3. Verify availability.
4. Deduct stock.
5. Record transaction.

## Stock Adjustment

1. Select product.
2. Enter adjustment quantity.
3. Select reason (Damaged, Lost, Found, Correction).
4. Update inventory.
5. Record adjustment in audit logs.

## Stock Transfer

1. Select source branch.
2. Select destination branch.
3. Choose products.
4. Confirm transfer.
5. Update inventory for both branches.
6. Record transfer history.
