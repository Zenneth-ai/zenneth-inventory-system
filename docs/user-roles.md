# ZIMS User Roles

## 1. Administrator
- Full system access
- Manage users
- Manage branches
- View all reports
- Configure system settings

## 2. Manager
- Manage inventory
- Approve purchases
- View reports
- Manage employees

## 3. Storekeeper
- Receive stock
- Issue stock
- Perform stock adjustments
- Record cylinder exchanges

## 4. Salesperson
- Process sales
- Register customers
- Print receipts
- Accept payments

## 5. Accountant
- Manage expenses
- Process payroll
- View financial reports

## 6. HR Officer
- Manage employee records
- Update salaries
- Leave management
