# ZIMS Barcode & Label Management

## Overview

ZIMS automatically generates a unique barcode for every product.

## Barcode Formats

- Code 128 (Default)
- Code 39
- EAN-13
- QR Code (Optional)

## Barcode Information

Each barcode links to:

- Product ID
- Product Name
- SKU
- Category
- Selling Price
- Branch

## Barcode Features

- Auto Generate
- Manual Generate
- Reprint Barcode
- Bulk Barcode Printing
- Export Barcode PDF

## Printing

Supported label sizes:

- 40 × 25 mm
- 50 × 30 mm
- 70 × 50 mm
- A4 Label Sheets

## Scanner Support

- USB Barcode Scanner
- Bluetooth Scanner
- Phone Camera (Future)

## POS Integration

At the Point of Sale:

1. Scan barcode
2. Product appears instantly
3. Quantity updates automatically
4. Stock reduces after sale

## Inventory Integration

Barcode scanning supports:

- Stock In
- Stock Out
- Stock Count
- Stock Transfer
