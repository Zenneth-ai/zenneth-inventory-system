# ZIMS Evidence & Document Management

## Overview

ZIMS allows employees to attach supporting evidence to important transactions.

Evidence becomes part of the permanent audit record.

---

## Supported Evidence

### Photos

- Damaged Products
- Damaged LPG Cylinders
- Returned Products
- Shelf Stock Count

### Documents

- Supplier Invoice
- Delivery Note
- Purchase Order
- Customer Receipt
- Credit Note
- Warranty Document

### Files

- PDF
- JPG
- PNG
- DOCX

---

## Transactions That Support Evidence

- Stock Adjustment
- Stock Transfer
- Product Return
- Customer Refund
- Cylinder Write-Off
- Purchase Receiving
- Expense Claim
- Price Change Approval

---

## Required Evidence

Evidence is mandatory for:

- Damaged Products
- Lost Inventory
- Refunds
- Cylinder Write-Off
- Manual Stock Adjustment
- Product Deletion

---

## Evidence Details

Every uploaded file stores:

- File Name
- File Type
- File Size
- Uploaded By
- Date
- Time
- Branch
- Related Transaction

---

## Security

- Files cannot be modified after approval.
- Every upload is recorded in the audit log.
- Only authorized users can view confidential documents.

---

## Search

Search evidence by:

- Employee
- Product
- Barcode
- Transaction ID
- Date
- Branch
- File Type
