# ZIMS Audit Log & Employee Activity Module

## Overview

Every important action performed in ZIMS is automatically recorded.

Audit logs cannot be edited or deleted by normal users.

## Permissions

### Cashier

- View Own Activity Only

### Manager

- View Branch Activity

### Super Admin

- View All Activity
- Export Logs
- Print Reports

---

## Security

- Logs cannot be modified
- Logs cannot be deleted
- Every action has a timestamp
- Every action is linked to a user
