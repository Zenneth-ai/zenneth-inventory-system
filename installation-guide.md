# Installation Guide

## Requirements
- Git
- Visual Studio Code
- XAMPP
- Composer
- Node.js
- PHP 8.3+
- Laravel 12

## Setup Steps
1. Clone the repository
2. Install PHP dependencies
3. Install JavaScript dependencies
4. Configure the .env file
5. Create the MySQL database
6. Run migrations
7. Start the development server

## Commands (to be used on the laptop)

composer install

npm install

php artisan migrate

php artisan serve
